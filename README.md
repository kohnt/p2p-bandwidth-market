# P2P Bandwidth Market

## Overview
A decentralized system enabling peer-to-peer mobile data sharing using NFC-based token exchange.

## Architecture Components
- Hotspot connectivity (Wi-Fi tethering)
- Proxy-based traffic routing
- Metering engine (NetworkStatsManager)
- NFC token exchange (HCE)
- Token-based session control

## Repository Structure
- apps/ -> Android applications
- shared/ -> protocol definitions (critical)
- experiments/ -> proof-of-concept modules
